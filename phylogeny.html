PRRSV-2 ORF5 Preliminary classification

Scientific scope

Sequence submission and preliminary classification

This prototype captures standardized metadata, validates nucleotide input, and prepares the request for comparison with curated PRRSV-2 ORF5 reference sequences. Phylogenetic lineage assignment will be enabled after the Python analysis service is connected.

Analysis scope

What this module will evaluate

  • Input format and nucleotide characters
  • Sequence length and ORF5 coverage
  • Ambiguous nucleotide proportion
  • Phylogenetic placement against curated references
  • Closest DiseasesMapMx reference sequences

Interpretation

Preliminary result only

Lineage assignment must be interpreted together with sequence quality, phylogenetic placement, reference coverage, and epidemiological context.

Percentage identity alone will not be used as the sole criterion for lineage assignment.

Privacy

Do not submit identifying farm data

Use coded sample identifiers. Farm names, producer names, street addresses, and exact geographic coordinates are not required for phylogenetic analysis.

Planned computational workflow

How the complete analysis will work

01

Validate

Standardize the nucleotide input, remove formatting, and evaluate sequence quality.

02

Align

Align the submitted ORF5 sequence against a curated PRRSV-2 reference dataset.

03

Classify

Estimate phylogenetic placement, lineage assignment, identity, coverage, and confidence.

04

Review

Store authorized requests privately for manual scientific review before any public use.
