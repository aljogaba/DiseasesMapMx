PRRSV-2 ORF5 Closest-reference screening

Scientific scope

Sequence submission and reference screening

This module captures standardized metadata, validates nucleotide input, and sends the request to a Python analysis engine for preliminary closest-reference comparison against curated PRRSV-2 ORF5 sequences.

Interpretation status

The current output is a preliminary closest-reference screening. It is not a formal phylogenetic lineage assignment and depends on the current reference panel.

Analysis scope

What this module evaluates

  • Input format and nucleotide characters
  • Sequence length and ORF5 coverage
  • Ambiguous nucleotide proportion
  • Closest-reference signal against curated ORF5 references
  • Closest reference and closest Mexican reference signals

Interpretation

Preliminary result only

Lineage assignment must be interpreted together with sequence quality, phylogenetic placement, reference coverage, and epidemiological context.

Percentage identity alone will not be used as the sole criterion for lineage assignment.

Privacy

Do not submit identifying farm data

Use coded sample identifiers. Farm names, producer names, street addresses, and exact geographic coordinates are not required for this screening.

Computational workflow

How the screening works

01

Validate

Standardize the nucleotide input, remove formatting, and evaluate sequence quality.

02

Align

Align the submitted ORF5 sequence against a curated PRRSV-2 reference dataset.

03

Screen

Report closest-reference lineage signal, identity, ORF5 coverage, support level, and uncertainty warnings.

04

Review

Store authorized requests privately for manual scientific review before any public use.
