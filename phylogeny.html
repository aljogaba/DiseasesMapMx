PRRSV-2 ORF5 Closest-reference screening

Scientific scope

Sequence submission and reference screening

This module captures standardized metadata, validates nucleotide input, and sends the request to a Python analysis engine for preliminary closest-reference comparison and local master-tree context against curated PRRSV-2 ORF5 references.

Interpretation status

This module provides a preliminary closest-reference screening result. It is not a formal phylogenetic lineage assignment and must be interpreted with the current reference panel and tree context.

Analysis scope

What this module evaluates

  • Input format and nucleotide characters
  • Sequence length and ORF5 coverage
  • Ambiguous nucleotide proportion
  • Closest-reference signal against curated ORF5 references
  • Closest reference and closest Mexican reference signals
  • Local master-tree context for represented references
  • ORF5 amino acid translation and vaccine-reference comparison

Interpretation

Preliminary result only

Lineage interpretation must be considered together with sequence quality, reference-panel coverage, local master-tree context, and epidemiological information.

Percentage identity alone is not used as the sole criterion for lineage interpretation.

Computational workflow

How the screening works

01

Validate

Standardize the nucleotide input, remove formatting, and evaluate sequence quality.

02

Screen

Compare the submitted ORF5 sequence against curated references using ungapped closest-reference identity.

03

Contextualize

Link the closest reference to the PRRSV-2 ORF5 master tree and show a reduced local tree view.

04

Translate

Translate ORF5 into GP5 amino acids and highlight coding-level differences against closest and vaccine references.

05

Review

Store authorized requests privately for manual scientific review before any public use.
