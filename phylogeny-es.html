Alcance científico

Envío de secuencias y tamizaje por referencia

Este módulo captura metadatos estandarizados, valida la entrada nucleotídica y envía la solicitud a un motor de análisis en Python para comparación preliminar por referencia cercana y contexto local del árbol maestro contra referencias curadas de PRRSV-2 ORF5.

Estatus de interpretación

Este módulo proporciona un resultado preliminar de tamizaje por referencia cercana. No constituye una asignación filogenética formal de linaje y debe interpretarse considerando el panel de referencia actual y el contexto del árbol.

Comparación de aminoácidos ORF5

Comparación traducida de GP5

La comparación de aminoácidos aparecerá después de traducir la secuencia en el marco codificante ORF5 inferido.

Qué muestra este paso

This step translates the submitted Secuencia ORF5 into amino acids using the orientation and reference-frame context inferred by the nucleotide screening. It compares the derived GP5 sequence against the closest reference and a fixed vaccine reference panel, helping separate coding-level amino acid changes from synonymous nucleotide variation.

Alcance del análisis

Qué evalúa este módulo

  • Input format and nucleotide characters
  • Secuencia length and ORF5 coverage
  • Ambiguous nucleotide proportion
  • Closest-reference signal against curated ORF5 references
  • Closest reference and closest Mexican reference signals
  • Local master-tree context for represented references
  • ORF5 amino acid translation and vaccine-reference comparison

Interpretación

Resultado preliminar únicamente

Linaje interpretation must be considered together with sequence quality, reference-panel coverage, local master-tree context, and epidemiological information.

La identidad porcentual por sí sola no se utiliza como criterio único para la interpretación de linaje.

Flujo computacional

Cómo funciona el tamizaje

01

Validar

Estandarizar la entrada nucleotídica, retirar formato y evaluar la calidad de la secuencia.

02

Tamizar

Comparar la secuencia ORF5 enviada contra referencias curadas mediante identidad por referencia cercana sin gaps.

03

Contextualizar

Vincular la referencia más cercana con el árbol maestro PRRSV-2 ORF5 y mostrar una vista local reducida del árbol.

04

Traducir

Traducir ORF5 a aminoácidos GP5 y resaltar diferencias a nivel codificante contra referencias cercanas y vacunales.

05

Revisar

Almacenar solicitudes autorizadas de forma privada para revisión científica manual antes de cualquier uso público.
